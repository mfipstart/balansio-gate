Одна страница: партнёр вводит ключ и разрешает GitHub создать приватный репозиторий с колесом.
Дальше — Vercel Import, переменных окружения не нужно.

Деплой: статика, `vercel --prod` или Import в Vercel, ничего настраивать не надо.
