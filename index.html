Копия создана

Репозиторий — создан приватным — проверять ничего не нужно. Осталось два действия.

  1. Один раз установите Vercel на GitHub. Пока приложения нет, Vercel не видит приватные репозитории, и поиск у него заблокирован — это его правило, не наше. Установить Vercel
  2. Импортируйте репозиторий на vercel.com/new — он появится в Import Git Repository. Имя проекта оставьте —, тогда адрес колеса будет —. Нажмите Deploy: переменные окружения не нужны.
  3. Проверьте подпись. Откройте своё колесо, зайдите в /admin, поправьте название проекта и ссылку на Telegram, нажмите «Сохранить».

Обновить копию

Обновляем — до текущей версии колеса. Обновляем копию до текущей версии колеса. Ваши настройки — название, ссылка на Telegram, бот — останутся как есть: меняются только файлы приложения.

Разрешение GitHub нужно, чтобы положить файлы в ваш репозиторий. После обновления Vercel пересоберёт сайт сам — это около минуты.

Копия обновлена

Файлы в — заменены на актуальные. Настройки и ссылки не тронуты.

  1. Подождите минуту. Vercel пересоберёт сайт автоматически. Если через пару минут изменений не видно — откройте проект в Vercel, Deployments → верхний деплой → ⋯ → Redeploy.
  2. Обновите админку. В левом меню появится кнопка «Инструкция», а в ней — пошаговая настройка своего бота.
