Копия создана

Приватный репозиторий уже в вашем аккаунте. Осталось подключить его к Vercel.

  1. Откройте репозиторий — и убедитесь, что он приватный.
  2. Зайдите на vercel.com/new, выберите Import Git Repository и этот репозиторий.
  3. В поле Project Name впишите ровно — — тогда адрес колеса будет предсказуемым: —
  4. Нажмите Deploy. Переменные окружения не нужны — ничего заполнять не надо.
  5. Откройте своё колесо, зайдите в /admin и проверьте название проекта и ссылку на ваш Telegram, затем нажмите «Сохранить».
